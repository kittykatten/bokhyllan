# Bokhyllan

Min läslogg: böcker, serier, priser, månadsplan och statistik.

- Appen: https://kittykatten.github.io/bokhyllan/
- Beta (nästa version att testa, samma data): https://kittykatten.github.io/bokhyllan/beta/
- Data sparas i Firebase (Firestore) under det inloggade Google-kontot. Inga böcker eller personuppgifter ligger i det här repot.
- Säkerhetskopia: Mer → Säkerhetskopia → Ladda ner säkerhetskopia.

Filer:
- `index.html` – hela appen
- `beta/` – nästa version under test, släpps genom att kopieras till roten
- `data/meta.json` – omslag, genrer och namnförslag från Open Library
- `sw.js`, `manifest.webmanifest`, `icons/` – gör att appen kan installeras på telefonen
